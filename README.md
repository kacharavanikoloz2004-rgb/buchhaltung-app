# Моя бухгалтерия: мини-приложение для Telegram

Здесь лежит только код программы (`index.html`). Данных бухгалтерии в этом репозитории нет и не будет.

Данные хранятся в личном проекте Supabase владельца. Открыть их может только владелец: на компьютере по секретному ключу, в Telegram по подписи его аккаунта.
